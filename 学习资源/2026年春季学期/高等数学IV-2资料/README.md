# 高等数学IV-2资料

## 内容简介

本资料面向高等数学 IV-2 期末复习，覆盖向量代数与空间解析几何、多元函数微分学、重积分和级数等内容。资料同时保留原始压缩包、分章节源文件与已整理的 LaTeX 工程，便于后续修订、重新编译和版本维护。
