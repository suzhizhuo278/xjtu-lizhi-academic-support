# 有机化学I-2资料

## 内容简介

本资料面向有机化学 I-2 期末复习，整理有机化学基础概念、醇酚、醚、醛酮、羧酸、羧酸衍生物、杂环、红外光谱、立体化学、官能团转化、试剂用途和典型题型。适合考前快速回顾与专题查漏补缺。
