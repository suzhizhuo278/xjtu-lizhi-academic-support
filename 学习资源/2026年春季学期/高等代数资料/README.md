# 高等代数资料

## 内容简介

本资料整理高等代数课程复习内容，覆盖多项式、域、线性空间、线性方程组、线性映射、矩阵表示、特征值、对角化、Jordan 标准形、内积空间、正交变换、酉空间与 Hermite 型等模块。适合期末复习和知识网络梳理。

## 内容目录

1. 一元多项式环、多项式整除、最大公因式与唯一因式分解
2. 重因式、多项式根、复数域和实数域上的不可约多项式
3. 有理数域上的不可约多项式、模剩余类环、域与域的特征
4. 线性空间、线性子空间、线性相关性、基与维数、矩阵的秩
5. 线性方程组解结构、子空间交与和、商空间、线性空间同构
6. 线性映射、核与像、矩阵表示、相似矩阵、特征值与特征向量
7. 可对角化条件、不变子空间、Hamilton-Cayley 定理与最小多项式
8. 幂零变换与一般线性变换的 Jordan 标准形
9. 实内积空间、标准正交基、正交补、正交变换与实对称矩阵
10. 酉空间、Hermite 变换、Hermite 型、应用举例、典型定理证明
11. 习题与思考题、公式与符号索引、参考文献
