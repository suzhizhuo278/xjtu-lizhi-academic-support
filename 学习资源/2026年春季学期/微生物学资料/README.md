# 微生物学资料

## 内容简介

本资料整理微生物学课程的期末复习内容，覆盖微生物概述、纯培养与显微技术、细胞结构、营养、代谢、生长控制、病毒、微生态、感染与免疫等主题。适合用于搭建知识框架、复盘名词概念和考前集中回顾。
