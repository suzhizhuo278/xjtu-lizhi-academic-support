# 复变函数资料

## 内容简介

本资料面向复变函数课程复习，先整理全纯函数、复初等函数、积分、级数、Cauchy 公式、Taylor 展开、留数公式等基础内容，再补充整函数、解析数论、黎曼曲面与模形式等拓展主题。适合系统复习与进阶阅读参考。
