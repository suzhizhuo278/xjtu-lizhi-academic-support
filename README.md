# 励志学辅资料集

用于西安交大励志书院学业辅导中心资料的统一整理与存储。

## 项目结构（仅 3 个一级目录）

```text
.
├── 学习资源/
  ├── 2025年秋季学期/
  ├── 2026年春季学期/
└── 模板/
```

## 各目录用途

- `学习资源/`：所有可供同学使用的学习资料。
- `模板/`：通知、复盘、资料说明等模板文件。

## 学习资源的统一格式（每个资料包）

每个资料包统一为：

```text
xx资料/
├── pdf/
├── src/
├── graph/
└── README.md
```

说明：
- `pdf/`：最终分发版本。
- `src/`：可编辑源文件（Word/PPT/Markdown 等）。
- `graph/`：图片、图表、截图。
- `README.md`：该资料内容简介（100字）+ 作者与审核列表 + 目录。

## 命名建议

统一格式：`YYYY《课程名》资料名.pdf`  
示例：`2026《高等数学IV-2》复习资料.pdf`
